### 4. Bug fix — stopping time line on log x-axis
- In dashboard_2, the stopping time vertical line was rendered using layout `shapes` with `yref: 'paper'`
- Bug: x coordinate was computed as `Math.log10(st)` manually, but Plotly already handles log scaling when `xref: 'x'` — causing the line to be double-log'd and land at the wrong position
- Fix: pass `st` directly; let Plotly handle axis scaling
