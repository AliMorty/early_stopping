## What Was Done

- **New module `ali_code/LLM_visualization/w_plane_trajectories.py`** with standalone functions
  (deliberately *not* methods, so Ali can read them and copy whatever he wants into the class):
  - `find_w_tilde(model, X, y)` — logistic-loss minimizer via the model's own GD (`model.grad`); for the
    **non-separable** case.
  - `find_w_tilde_svm(X, y, normalize=False)` — the **exact max-margin / hard-margin SVM** solution
    (`w_tilde` = the direction logistic GD only approaches at rate ~1/log t). Solved as a QP.
  - `collect_w_trajectory(model, X, y, n_steps)` — re-runs GD and returns the `(n_steps+1, d)` array of
    weights visited. Needed because `run_GD_for_t_steps` records **losses**, not the `w` sequence the
    plane plots require.
  - `basis_from_vectors(w_1, w_2)` — Gram–Schmidt → orthonormal `(d,2)` plane (axis 1 = `w_1` dir,
    axis 2 = `w_2`'s orthogonal part). Either axis can be a `w_tilde`.
  - `pca_basis(w_points)` — automatic 2D plane (top-2 SVD directions) for the "auto-project d-dim into
    2 representative dims" idea.
  - `project(W, B, mean)` and `plot_trajectory_over(w_1, w_2, trajectory_dict, ...)` — plots each
    trajectory in the plane (start = square, end = star, optional `mark_points` for `w*`/`w_tilde`).

- **`w_tilde` = max-margin solution.** Discussed that GD is the *slow* way to get it (log-rate
  convergence in direction, ‖w‖→∞). The efficient route is solving the hard-margin SVM QP directly:
  `min ½‖w‖² s.t. yᵢ(xᵢ·w) ≥ 1`.

- **Chose a real library over hand-rolled code.** Started with a scipy-SLSQP version, then per Ali's
  preference switched to **cvxpy** (installed `cvxpy 1.9.2` + solver backends clarabel/osqp/scs). The
  function is now the textbook QP handed to cvxpy; raises if the data isn't separable (status
  `infeasible`). Module deps are now numpy, matplotlib, cvxpy (scipy import dropped).

- **Normalization clarified.** `normalize=False` is the right default: for plotting/direction-comparison
  the norm is irrelevant (`basis_from_vectors` normalizes internally); the unnormalized `w` carries the
  meaningful geometry (margin exactly 1). The flag is only for when a pure unit direction is wanted.

- **Smoke-tested** everything end-to-end (fake model + separable data): SVM recovers min-margin = 1.0 and
  cos ≈ 0.994 to the true separating direction; basis/PCA/projection/plot all run.
