## Topic
Building a from-scratch logistic regression simulation to replicate Figure 1 from the paper "Benefits of Early Stopping in Gradient Descent for Overparameterized Logistic Regression" (Wu et al., 2025).

## What We Discussed

### Paper — Figure 1 Setup
- Read and discussed the paper setup: x ~ N(0, Σ), y | x ~ logistic(x^T w*), with d=2000, n=1000, λ_i = i^{-2}, w*_{0:100} = 1, w*_{100:∞} = 0.
- Clarified what Σ is: eigenvalues alone don't determine Σ, but the simulation works in the eigenbasis, so Σ is effectively diagonal with entries λ_i = i^{-2}. The eigenvectors are implicitly the standard basis.
- Data generation: sample z ~ N(0, I), then x = sqrt(λ) * z elementwise. No need to instantiate the full Σ matrix.

### Bugs Found and Fixed
- `w_0 = np.zeros(self.d).reshape(-1,1)` caused a shape `(d,1)` which led to `y_data * (X_data @ w)` broadcasting to `(n,n)` instead of `(n,)`, silently computing wrong gradients. Fixed by removing the reshape.
- `return` on its own line before the dict caused the function to return `None`. Fixed by putting `{` on the same line as `return`.
- `record_the_error` is missing `self` as first parameter — noted but not yet fixed (currently commented out).

### Key Concepts Discussed
- Why `(n,)` vs `(n,1)` matters in NumPy: the math formula uses a sum over i, but vectorized code requires consistent shapes. `(n,) * (n,1)` broadcasts to `(n,n)` (outer product), not elementwise.
- Optimization length ηt as the x-axis: more meaningful than raw iteration count because it normalizes across different step sizes.
