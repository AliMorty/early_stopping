## What We Did

### Interactive Jupyter Visualization (`ali_code/`)

Started from the existing notebook `ali_code/LOOCV-holdout-set-plots.ipynb`, which runs gradient descent on synthetic linear regression data and plots train/validation risk over iterations using static matplotlib.

The goal was to make an interactive version (like Dashboard 2) but inside Jupyter rather than as a standalone HTML file.

**Created two new files:**

- `ali_code/trajectory_plotter.py` — extracted the `TrajectoryValidationRiskPloter` class into a plain `.py` module so it can be properly imported without executing side-effect cells.
- `ali_code/sonnet_visualization.ipynb` — new notebook with an interactive plotly + ipywidgets dashboard:
  - X-scale and Y-scale toggle buttons (linear / log)
  - Plotly `FigureWidget` that updates in-place
  - Parameter inputs (n, p, seed, eta, max_T) with a Rerun button
  - `parse_int()` helper accepting shorthand notation (`6k`, `6e3`, etc.)
  - Error display in the status label if a bad value is entered

**Debugging along the way:**
- First attempt used `%%capture %run LOOCV-holdout-set-plots.ipynb` which executed all cells including the slow GD run, freezing the kernel
- Switched to a proper `.py` module import to fix this
- VS Code kernel appeared frozen even on `print('hey')` — turned out the kernel was still stuck from the previous hung run; a restart fixed it
- `plotly.FigureWidget` required `anywidget` to be installed separately (`~/.venv/bin/pip install anywidget`)

**UI refinements applied:**
- Widened parameter fields from 130px to 180px
- Switched from `IntText` to `Text` widgets to allow shorthand input (`6k`, `6e3`)
