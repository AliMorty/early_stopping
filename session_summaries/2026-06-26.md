## Class Changes in `LOOCV-holdout-set-plots.ipynb`

Ali heavily refactored `TrajectoryValidationRiskPloter` across multiple saves this session:

- **LOOCV implemented**: `run_LOOCV` loops over training samples, runs GD leaving one out each time, accumulates error, divides by `n`. Uses `run_GD_efficient` internally.
- **`run_GD_efficient` redesigned**: now has flags `train_error_tracking`, `valid_error_tracking`, `test_error_tracking` to avoid unnecessary computation. Error is recorded *before* the grad step (at `w_0, w_1, ..., w_{max_T-1}`). `max_T` is now a parameter.
- **`run_hold_out_GD`**: generates train/valid/test sets separately, calls `run_GD_efficient`. Accepts `max_T`, `eta`, `test_error_tracking`, `test_sample_size`.
- **`generate_samples_and_run_LOOCV`**: generates data and runs LOOCV. Accepts `max_T`, `eta`, `test_error_tracking`, `test_sample_size`.
- **`generate_data`**: uses `self.rng` (set in `__init__`) instead of a per-call seed. Isotropic path uses `standard_normal` for efficiency. Non-isotropic path fixed (was assigning to `y` instead of `X`).
- **`plot_trajectories`**: takes a `dict` of label→array, plots whichever are non-None.

## `sonnet_visualization.ipynb` — Current State

Interactive Jupyter dashboard using `plotly FigureWidget` + `ipywidgets`. Opens with an empty plot; nothing runs until a button is clicked.

**Parameters** (shared between both buttons): `n`, `p`, `seed`, `eta`, `max_T`, `m` (holdout valid size), `n_test`

**Buttons:**
- `Run Holdout` (blue): runs `run_hold_out_GD`, updates Train + Valid traces (+ Holdout Test if checkbox checked)
- `Run LOOCV` (orange): runs `generate_samples_and_run_LOOCV`, updates LOOCV trace (+ LOOCV Test if checkbox checked)

**5 traces**: Train (steelblue), Valid (tomato), Holdout Test (seagreen), LOOCV (mediumpurple), LOOCV Test (darkorange)

**Other features**: X/Y scale toggles (green = selected), `6k`/`6e3` shorthand in number fields, both buttons disabled while running, error shown in status label.

**Shorthand parsing**: `parse_int('6k') = 6000`, `parse_int('6e3') = 6000`.
